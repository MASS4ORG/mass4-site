Indicates the reason why focus was requested or changed.

## Enum Values

- **Programmatic**: Focus was set programmatically via code.
- **Keyboard**: Focus was changed via keyboard navigation (Tab/Shift+Tab).
- **Mouse**: Focus was changed via mouse click.
