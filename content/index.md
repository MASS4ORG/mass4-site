<section class="section">
  <div class="wrap">
    <div class="section-head reveal">
      <span class="eyebrow">The MEGA4 initiative</span>
      <h2>Four interconnected projects</h2>
      <p>Each project is useful on its own, but they're designed to build on one another — the layer below is the foundation for the layer above.</p>
    </div>
    <div class="pillars">
      <a class="pillar g reveal" href="/guinevere">
        <span class="role">Foundation · GUI</span>
        <h3>Guinevere</h3>
        <p>A GPU-native, immediate-mode UI toolkit. Planned as a Zig fork of <a href="https://github.com/david-vanderson/dvui">DVUI</a>, tuned for the rest of the stack.</p>
        <span class="more">Learn more →</span>
      </a>
      <a class="pillar ga reveal" href="/gaya">
        <span class="role">Tool · Editor</span>
        <h3>Gaya</h3>
        <p>A lightweight, general text editor and plugin platform built on Guinevere. The host that Turian Studio will plug into.</p>
        <span class="more">Learn more →</span>
      </a>
      <a class="pillar t reveal" href="/turian">
        <span class="role">Engine · 3D</span>
        <h3>Turian</h3>
        <p>A component-based 3D game engine and editor in pure Zig. Has its own dedicated site at turian.mass4.org.</p>
        <span class="more">Learn more →</span>
      </a>
      <a class="pillar m reveal" href="/mystery">
        <span class="role">Goal · Game</span>
        <h3>Mystery</h3>
        <p>A game built with the stack above and shaped by the community. The end-to-end test that everything else exists to support.</p>
        <span class="more">Learn more →</span>
      </a>
    </div>
  </div>
</section>

        <h4>Open by default</h4>
        <p>Code, assets, and decisions are public from the first commit — not at some future launch.</p>
      </div>
      <div class="fact reveal">
        <h4>One language</h4>
        <p>The whole stack is Zig. We recently moved off C#/.NET to a single, lower-level toolchain.</p>
      </div>
      <div class="fact reveal">
        <h4>Honest about stage</h4>
        <p>These are works in progress. We'd rather show the rough edges than oversell a roadmap.</p>
