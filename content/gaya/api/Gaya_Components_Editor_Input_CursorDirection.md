Direction for cursor movement

## Enum Values

- **Left**: Move cursor left by one character
- **Right**: Move cursor right by one character
- **Up**: Move cursor up by one line
- **Down**: Move cursor down by one line
- **LineStart**: Move cursor to the beginning of the current line
- **LineEnd**: Move cursor to the end of the current line
- **PageUp**: Move cursor up by one page
- **PageDown**: Move cursor down by one page
