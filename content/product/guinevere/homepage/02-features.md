## Core Features

Guinevere delivers everything you need for modern GUI development:

### Performance First
- Zero-allocation rendering where possible
- Optimized draw call batching
- Minimal CPU overhead
- GPU-accelerated rendering

### Developer Experience
- Immediate mode paradigm
- No complex state management
- Hot reload support
- Comprehensive debugging tools

### Rich Controls
- Standard UI elements (buttons, inputs, sliders)
- Advanced layouts (flex, grid, absolute)
- Custom drawing primitives
- Theme and styling system
