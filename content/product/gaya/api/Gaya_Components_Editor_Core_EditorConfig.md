Configuration and styling options for the text editor

## Properties

### **LineHeight**

(*float*) { get; set } = `16.0f`: Gets or sets the height of each line in pixels

### **LineNumberWidth**

(*float*) { get; set } = `50.0f`: Gets or sets the width of the line number area in pixels

### **ShowLineNumbers**

(*bool*) { get; set } = `true`: Gets or sets a value indicating whether line numbers should be displayed

### **IsReadOnly**

(*bool*) { get; set } = `false`: Gets or sets a value indicating whether the editor is read-only

### **TabSize**

(*int*) { get; set } = `4`: Gets or sets the number of spaces to display for a tab character

### **WordWrap**

(*bool*) { get; set } = `false`: Gets or sets a value indicating whether word wrapping is enabled

### **SyntaxHighlighting**

(*bool*) { get; set } = `false`: Gets or sets a value indicating whether syntax highlighting is enabled

### **MaxUndoSteps**

(*int*) { get; set } = `100`: Gets or sets the maximum number of undo steps to maintain

### **CursorBlinkInterval**

(*double*) { get; set } = `500`: Gets or sets the cursor blink interval in milliseconds

### **KeyRepeatDelay**

(*double*) { get; set } = `500`: Gets or sets the delay before key repeat starts in milliseconds

### **KeyRepeatInterval**

(*double*) { get; set } = `50`: Gets or sets the interval between key repeats in milliseconds
