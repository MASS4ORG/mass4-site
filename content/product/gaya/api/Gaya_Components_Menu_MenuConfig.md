Configuration for the hierarchical menu

## Properties

### **MenuWidth**

(*float*) { get; set } = `200f`: Gets or sets the width of the menu in pixels

### **ItemHeight**

(*float*) { get; set } = `24f`: Gets or sets the height of each menu item in pixels

### **SeparatorHeight**

(*float*) { get; set } = `1f`: Gets or sets the height of separator lines in pixels

### **SubmenuOffset**

(*float*) { get; set } = `5f`: Gets or sets the offset for submenu positioning in pixels

### **IconSize**

(*float*) { get; set } = `16f`: Gets or sets the size of menu icons in pixels

### **Padding**

(*float*) { get; set } = `8f`: Gets or sets the internal padding of menu items in pixels

### **ShowIcons**

(*bool*) { get; set } = `true`: Gets or sets a value indicating whether icons should be displayed in the menu

### **ShowShortcuts**

(*bool*) { get; set } = `true`: Gets or sets a value indicating whether keyboard shortcuts should be displayed in the menu

### **MaxVisibleItems**

(*int*) { get; set } = `10`: Gets or sets the maximum number of items visible in the menu before scrolling
